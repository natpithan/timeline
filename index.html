☁ ซิงค์ข้อมูลผ่าน GitHub

1) สร้าง repo Private แยกต่างหาก (เช่น timeline-data) — ห้ามใช้ repo เดียวกับที่ทำ GitHub Pages เพราะเป็น public

3) วาง token ด้านล่าง (ต้องกรอกในแต่ละเครื่องครั้งเดียว: PC และมือถือ)
